# Library Management System

[![Domain: Information Systems](https://img.shields.io/badge/Domain-Information%20Systems-blue.svg)]()
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

> A structured software system for library cataloging, managing book inventories, tracking member borrowing histories, and calculating fine fees for overdue books.

---

## ✨ Core Features

- **Book Catalog CRUD**: Add, edit, remove, and index books by ISBN, author, and category.
- **Member Management**: Track member registrations, active loans, and borrowing limits.
- **Checkout & Return Workflows**: Automated loan tracking and overdue fine calculation.
