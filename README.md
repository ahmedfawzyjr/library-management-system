## ⚙️ Getting Started & Local Setup

### Prerequisites
- JDK 17+
- Apache Maven

### Installation & Run Steps

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/ahmedfawzyjr/library-management-system.git
   cd library-management-system
   ```

2. **Install Dependencies**:
   ```bash
   mvn clean install
   ```

3. **Configure Environment**:
   ```bash
   cp .env.example .env
   ```

4. **Run Application**:
   ```bash
   mvn exec:java
   ```
