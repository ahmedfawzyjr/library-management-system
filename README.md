## 📌 Overview
Object-oriented Java desktop application for library book inventory management, member tracking, borrowing transactions, and overdue fine calculations.

## ✨ Key Features
- **Modern Architecture**: Clean, modular structure for scalability and maintainability.
- **Automated Testing & CI/CD**: Verified GitHub Actions workflows for reliable integration.
- **Security Policy**: Comprehensive security guidelines and vulnerability reporting standard.

## 🛠️ Technology Stack
- **Languages**: Java
- **Platform**: GitHub Actions CI/CD, Cross-platform compatibility

## 🚀 Getting Started

### Prerequisites
Ensure you have the required runtime environment installed for `Java`.

### Installation
```bash
git clone https://github.com/ahmedfawzyjr/library-management-system.git
cd library-management-system
```

### Running Tests
```bash
# Execute local test suite
mvn test
```
